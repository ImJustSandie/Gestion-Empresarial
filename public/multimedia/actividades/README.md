# Multimedia - Actividades

Carpeta destinada a almacenar el contenido multimedia del módulo de actividades y tareas.

Ejemplos de archivos permitidos:
- Imágenes de actividades (`.jpg`, `.png`, `.svg`, `.webp`)
- Videos instructivos (`.mp4`, `.webm`)
- Audios o grabaciones (`.mp3`, `.ogg`)
- Documentos adjuntos (`.pdf`)

Estos archivos son de acceso público y se sirven desde la raíz del sitio.
