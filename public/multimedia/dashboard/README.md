# Multimedia - Dashboard

Carpeta destinada a almacenar el contenido multimedia del módulo de dashboard.

Ejemplos de archivos permitidos:
- Imágenes de gráficas o iconos (`.jpg`, `.png`, `.svg`, `.webp`)
- Capturas de reportes (`.png`, `.jpg`)
- Recursos visuales para estadísticas (`.svg`, `.webp`)

Estos archivos son de acceso público y se sirven desde la raíz del sitio.
