# Multimedia - Enseñanza

Carpeta destinada a almacenar el contenido multimedia del módulo de enseñanza.

Ejemplos de archivos permitidos:
- Imágenes (`.jpg`, `.png`, `.svg`, `.webp`)
- Videos (`.mp4`, `.webm`)
- Audios (`.mp3`, `.ogg`)
- Documentos complementarios (`.pdf`)

Estos archivos son de acceso público y se sirven desde la raíz del sitio.
